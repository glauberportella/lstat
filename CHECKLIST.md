# Checklist — LSTAT (Little Statistics)

## 1. Estatística descritiva — essencial

### Prioridade 1

- [ ] stat_sum() — somatório dos valores.
- [ ] stat_count() — quantidade de observações.
- [ ] stat_min() — menor valor.
- [ ] stat_max() — maior valor.
- [ ] stat_range() — amplitude (máximo − mínimo).
- [ ] stat_mean() — média aritmética.
- [ ] stat_median() — mediana.
- [ ] stat_mode() — moda.
- [ ] stat_geometric_mean() — média geométrica.
- [ ] stat_harmonic_mean() — média harmônica.

##2. Medidas de dispersão

### Prioridade 1

- [ ] stat_variance() — variância populacional.
- [ ] stat_sample_variance() — variância amostral.
- [ ] stat_stddev() — desvio padrão populacional.
- [ ] stat_sample_stddev() — desvio padrão amostral.
- [ ] stat_mad() — desvio absoluto médio.
- [ ] stat_median_absolute_deviation() — desvio absoluto mediano.
- [ ] stat_iqr() — intervalo interquartil.
- [ ] stat_cv() — coeficiente de variação.

##3. Posição e distribuição dos dados

### Prioridade 1

- [ ] stat_quantile() — quantil.
- [ ] stat_percentile() — percentil.
- [ ] stat_quartile() — quartis.
- [ ] stat_zscore() — escore padronizado.
- [ ] stat_skewness() — assimetria.
- [ ] stat_kurtosis() — curtose.

## 4. Associação entre variáveis

### Prioridade 2

Estas operações serão particularmente úteis quando você chegar ao ML.

- [ ] stat_covariance() — covariância populacional.
- [ ] stat_sample_covariance() — covariância amostral.
- [ ] stat_correlation() — correlação de Pearson.
- [ ] stat_rank_correlation() — correlação de Spearman.
- [ ] stat_covariance_matrix() — matriz de covariância.
- [ ] stat_correlation_matrix() — matriz de correlação.

## 5. Transformação e normalização

###Prioridade 2

- [ ] stat_normalize_minmax() — normalização Min-Max.
- [ ] stat_standardize() — padronização Z-score.
- [ ] stat_center() — centralização pela média.
- [ ] stat_scale() — escalonamento pelo desvio padrão.
- [ ] stat_clip() — limitação de valores a um intervalo.

## 6. Estatísticas incrementais

###Prioridade 2

Interessante para estudar algoritmos, ponteiros e processamento de dados sem precisar armazenar todos os valores.

- [ ] stat_online_mean() — média incremental.
- [ ] stat_online_variance() — variância incremental.
- [ ] stat_online_stddev() — desvio padrão incremental.
- [ ] stat_online_covariance() — covariância incremental.
- [ ] stat_online_correlation() — correlação incremental.
